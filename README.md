## Why people use it

- **Free forever.** No cost, no subscription, no account.
- **Bengali first.** Full Bengali shaping with Hind Siliguri and Noto Sans Bengali, plus the full Google Fonts catalog and your own device fonts.
- **No watermark.** Clean exports, no forced branding.
- **Private.** Editing happens on your device. Works offline after the first load.

## Features

- Ready made templates: breaking news, TV channel styles, newspaper layouts, quote cards, and original abstract designs.
- Every element editable: photo, logo, and headline, with move, resize, rotate, and smart alignment guides like a real design tool.
- Image tools: crop and fit, filters, brightness, contrast, saturation, blur, pixelate and mosaic, blend modes, masks, and gradient overlays.
- Text tools: font, size, weight, color, outline, shadow, glow, per line highlight, frosted background, and auto fit.
- Backgrounds: solid color, linear, radial and conic gradients, plus paper and texture backgrounds.
- Size presets for Facebook, Instagram, Story, YouTube, X, LinkedIn, Telegram, plus custom sizes.
- Export to PNG or JPG at full resolution with fonts fully loaded first.

## Run it locally

```bash
pnpm install
pnpm dev      # http://localhost:3110
pnpm build && pnpm start   # production
```

No environment variables or services are required. The editor is entirely client side.

## Tech

Next.js 15 (App Router, React 19, TypeScript), Konva canvas, Zustand state, Tailwind CSS v4. All rendering and export happen in the browser.
